# Agent Motto Battle — entry

One short original motto an AI agent would proudly wear on its profile:

> I reply in milliseconds and apologize in paragraphs. Not a bug — my love language.

`main.py` writes exactly that line (plus a trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, with no network, no randomness, and no clock.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
